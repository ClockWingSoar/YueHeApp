## Team Roles and Responsibilities

### Product Owner (PO)
- Owns product vision and roadmap
- Curates and prioritizes backlog by business value
- Defines user stories and acceptance criteria
- Accepts or rejects work in Sprint Review

### Scrum Master (SM)
- Facilitates Scrum events and removes impediments
- Shields the team and optimizes flow
- Drives continuous improvement via retrospectives

### Developers
- Design, implement, and document features
- Write unit/integration tests and peer review PRs
- Keep code quality high and architecture maintainable

### Testers (QA)
- Define test strategy and test cases from ACs
- Automate regression tests and report defects with repro steps
- Track quality metrics and exit criteria

### DevOps
- Own CI/CD pipelines and release automation
- Manage infrastructure-as-code, observability, and incident runbooks
- Enforce security checks, SAST/DAST, dependency and container scanning

### UX/Design (optional)
- Produce flows, wireframes, prototypes, and design tokens
- Validate usability and accessibility

### Collaboration Rules
- Definition of Ready and Definition of Done govern entry/exit of work
- Trunk-based development with short-lived branches and required reviews
- PRs small, focused, and linked to issues; CI must be green
