# YueHeApp 悦和国际美容院管理系统需求文档

## 项目概述

**项目名称**: 悦和国际美容院管理系统 (YueHeApp)  
**项目类型**: 企业级美容院运营管理平台  
**技术架构**: Spring Boot 2.1.6 + Spring Data JPA + Thymeleaf + MySQL  
**开发模式**: 多模块Maven项目 (yuehe-common, yuehe-backend, yuehe-web)  

## 业务背景

悦和国际是一家专业的美容院连锁企业，致力于为客户提供高品质的美容服务。系统旨在通过数字化管理提升运营效率，实现客户关系管理、销售业绩跟踪、员工管理、财务分析等核心业务功能。

## 核心业务实体

### 1. 客户管理 (Client)
- **客户基本信息**: ID、姓名、年龄、性别、症状描述
- **关联美容院**: 客户归属的美容院
- **客户问卷**: 详细的客户需求调研
- **服务历史**: 客户的所有销售记录

### 2. 美容院管理 (CosmeticShop)
- **基本信息**: ID、名称、负责人、联系方式、地址、规模
- **会员数量**: 当前会员总数
- **折扣政策**: 美容院专属折扣率
- **店铺提成**: 业绩达标后的返利规则
- **客户管理**: 该美容院下的所有客户

### 3. 销售管理 (Sale)
- **销售记录**: 开卡总金额、实际回款、公司收到回款
- **关联信息**: 客户、美容项目、销售员工
- **提成计算**: 员工提成、店铺提成
- **开卡信息**: 开卡日期、项目数量、描述
- **操作记录**: 该销售的所有操作详情

### 4. 美容项目 (BeautifySkinItem)
- **项目信息**: ID、名称、价格、描述
- **销售关联**: 该项目的所有销售记录

### 5. 员工管理 (Employee)
- **基本信息**: ID、姓名、薪资、生日、描述
- **在职状态**: 是否离职
- **业务关联**: 销售记录、操作记录、职责分配

### 6. 操作管理 (Operation)
- **操作记录**: 操作日期、描述
- **关联信息**: 销售记录、操作员工、使用仪器
- **工具使用**: 具体使用的美容仪器

### 7. 仪器管理 (Tool)
- **仪器信息**: ID、名称、专业领域、价格
- **采购信息**: 购买日期、购买渠道、操作费用
- **使用记录**: 该仪器的所有操作记录

### 8. 用户管理 (User)
- **账户信息**: ID、用户名、密码、角色
- **权限控制**: 基于角色的访问控制

### 9. 角色管理 (Role)
- **角色定义**: 专家、操作人等不同角色
- **权限分配**: 不同角色的系统权限

### 10. 职责管理 (Duty)
- **职责分配**: 员工与角色的关联关系
- **权限控制**: 基于职责的功能权限

### 11. 客户档案 (Profile)
- **档案信息**: 剩余卡片数量、创建档案日期、描述
- **关联销售**: 与具体销售记录的关联

### 12. 客户问卷 (ClientQuestionare)
- **问卷内容**: 详细的客户需求调研
- **客户关联**: 与具体客户的关联关系

## 业务流程

### 1. 客户管理流程
1. 客户注册 → 填写基本信息 → 选择归属美容院 → 保存客户信息
2. 客户查询 → 输入查询条件 → 显示客户列表 → 选择客户查看详情
3. 客户编辑 → 选择客户 → 修改信息 → 保存更新
4. 客户问卷 → 选择客户 → 填写问卷 → 保存问卷信息

### 2. 销售管理流程
1. 创建销售 → 选择客户 → 选择美容项目 → 选择销售员工 → 填写销售信息 → 保存销售记录
2. 销售查询 → 输入查询条件 → 显示销售列表 → 选择销售查看详情
3. 提成计算 → 系统自动计算员工提成和店铺提成 → 更新销售记录

### 3. 操作管理流程
1. 记录操作 → 选择销售记录 → 选择操作员工 → 选择使用仪器 → 填写操作信息 → 保存操作记录
2. 操作查询 → 输入查询条件 → 显示操作列表 → 选择操作查看详情

### 4. 报表生成流程
1. 选择报表类型 → 设置查询条件 → 生成报表数据 → 导出报表文件
2. 支持按日期、员工、美容院等维度进行数据筛选和统计
