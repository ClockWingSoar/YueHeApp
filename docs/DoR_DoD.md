## Definition of Ready (DoR)
- Story has a clear problem statement and business value
- Acceptance criteria are testable and unambiguous
- Dependencies and risks identified; external teams aligned
- UI/UX artifacts (if applicable) attached or linked
- Estimable within a single sprint

## Definition of Done (DoD)
- Code implemented, reviewed, and merged to main
- Unit tests added/updated; coverage meets threshold
- Integration/e2e tests updated and green in CI
- Linting, formatting, and type checks pass
- Security/dependency checks pass
- Feature toggled if needed and documented in CHANGELOG
- Deployed to test/staging; PO acceptance provided
