# YueHeApp 功能需求详细说明

## 1. 用户认证与授权模块

### 1.1 用户登录
**功能描述**: 系统用户通过用户名和密码登录系统

**输入参数**:
- 用户名 (username): 必填，字符串类型
- 密码 (password): 必填，字符串类型

**处理逻辑**:
1. 验证用户名和密码格式
2. 查询数据库验证用户存在性
3. 验证密码正确性
4. 创建用户会话
5. 记录登录日志

**输出结果**:
- 登录成功：跳转到主页面
- 登录失败：显示错误信息

**异常处理**:
- 用户名不存在：提示"用户不存在"
- 密码错误：提示"密码错误"
- 账户被锁定：提示"账户已被锁定"

### 1.2 用户登出
**功能描述**: 用户安全退出系统

**处理逻辑**:
1. 清除用户会话
2. 记录登出日志
3. 跳转到登录页面

### 1.3 角色管理
**功能描述**: 管理系统用户角色和权限

**角色类型**:
- 专家 (Expert): 具有所有功能权限
- 操作人 (Operator): 具有基础操作权限
- 管理员 (Admin): 具有系统管理权限

**权限矩阵**:
| 功能模块 | 专家 | 操作人 | 管理员 |
|----------|------|--------|--------|
| 客户管理 | 全部 | 查看、新增 | 全部 |
| 销售管理 | 全部 | 查看、新增 | 全部 |
| 操作管理 | 全部 | 全部 | 全部 |
| 员工管理 | 查看 | 查看 | 全部 |
| 系统管理 | 查看 | 无 | 全部 |

## 2. 客户管理模块

### 2.1 客户注册
**功能描述**: 新增客户基本信息

**输入参数**:
- 客户ID (id): 自动生成，格式：kh + 数字
- 客户姓名 (name): 必填，最大长度100字符
- 年龄 (age): 可选，整数类型
- 性别 (gender): 可选，枚举值：男、女
- 症状描述 (symptom): 可选，最大长度500字符
- 美容院ID (shop_id): 必填，外键关联

**业务规则**:
1. 客户ID自动生成，格式为"kh" + 6位数字
2. 客户姓名不能为空
3. 年龄范围：0-120岁
4. 性别只能是"男"或"女"
5. 美容院必须存在且有效

**处理逻辑**:
1. 验证输入参数
2. 生成客户ID
3. 检查美容院是否存在
4. 保存客户信息到数据库
5. 记录操作日志

### 2.2 客户查询
**功能描述**: 根据条件查询客户信息

**查询条件**:
- 客户姓名：模糊匹配
- 美容院：精确匹配
- 年龄范围：区间查询
- 性别：精确匹配
- 创建时间：日期范围查询

**输出结果**:
- 客户列表（分页显示）
- 客户总数
- 查询条件保持

**分页参数**:
- 每页显示数量：默认20条
- 当前页码：默认第1页
- 排序字段：默认按ID排序
- 排序方向：默认升序

### 2.3 客户编辑
**功能描述**: 修改客户基本信息

**输入参数**: 同客户注册，ID不可修改

**业务规则**:
1. 只能修改非ID字段
2. 修改后的数据必须通过验证
3. 如果客户有关联的销售记录，需要特殊处理

**处理逻辑**:
1. 验证客户ID存在性
2. 验证输入参数
3. 检查是否有业务约束
4. 更新客户信息
5. 记录修改日志

### 2.4 客户删除
**功能描述**: 删除客户记录

**业务规则**:
1. 如果客户有关联的销售记录，不能直接删除
2. 需要先删除关联的销售记录
3. 删除操作不可逆

**处理逻辑**:
1. 检查客户是否存在
2. 检查是否有关联数据
3. 如果有关联数据，提示用户先删除关联数据
4. 如果没有关联数据，执行删除操作
5. 记录删除日志

### 2.5 客户问卷管理
**功能描述**: 管理客户需求调研问卷

**问卷内容**:
- 皮肤类型：干性、油性、混合性、敏感性
- 主要问题：痘痘、色斑、皱纹、松弛等
- 期望效果：美白、抗衰、补水、紧致等
- 预算范围：1000以下、1000-3000、3000-5000、5000以上
- 服务偏好：仪器、手工、综合等

**处理逻辑**:
1. 选择客户
2. 填写问卷内容
3. 保存问卷信息
4. 关联到客户记录

3. 设置生效时间
4. 保存折扣规则
5. 应用到相关销售计算

## 4. 销售管理模块

### 4.1 销售记录创建
**功能描述**: 创建新的销售记录

**输入参数**:
- 销售ID (id): 自动生成，格式：xs + 数字
- 客户ID (client_id): 必填，外键关联
- 美容项目ID (beautify_skin_item_id): 必填，外键关联
- 销售员工ID (seller_id): 必填，外键关联
- 项目数量 (item_number): 必填，1-36之间
- 开卡总金额 (create_card_total_amount): 必填，大于0
- 实际回款 (received_amount): 必填，大于等于0
- 公司收到回款 (received_earned_amount): 必填，大于等于0
- 员工提成 (employee_premium): 可选，0-1之间
- 店铺提成 (shop_premium): 可选，0-1之间
- 开卡日期 (create_card_date): 必填，日期格式
- 描述 (description): 可选，最大长度1000字符

**业务规则**:
1. 销售ID自动生成，格式为"xs" + 6位数字
2. 客户、美容项目、销售员工必须存在且有效
3. 项目数量范围：1-36
4. 实际回款不能超过开卡总金额
5. 公司收到回款不能超过实际回款
6. 提成比例范围：0-1

**处理逻辑**:
1. 验证输入参数
2. 检查关联实体存在性
3. 自动计算提成（如果未指定）
4. 保存销售记录
5. 更新相关统计数据
6. 记录操作日志

### 4.2 提成计算
**功能描述**: 自动计算员工和店铺提成

**计算规则**:
1. 员工提成 = 开卡总金额 × 员工提成比例
2. 店铺提成 = 开卡总金额 × 店铺提成比例
3. 提成比例根据员工角色和美容院政策确定

**处理逻辑**:
1. 获取员工角色信息
2. 获取美容院折扣政策
3. 根据业务规则计算提成
4. 更新销售记录
5. 记录计算日志

### 4.3 销售查询
**功能描述**: 根据条件查询销售记录

**查询条件**:
- 客户姓名：模糊匹配
- 美容院：精确匹配
- 销售员工：精确匹配
- 美容项目：精确匹配
- 开卡日期：日期范围查询
- 金额范围：区间查询

**输出结果**:
- 销售列表（分页显示）
- 销售总额统计
- 提成总额统计
- 客户数量统计

### 4.4 销售统计
**功能描述**: 生成销售统计报表

**统计维度**:
- 按时间：日、周、月、年
- 按员工：个人业绩统计
- 按美容院：店铺业绩统计
- 按美容项目：项目销售统计
- 按客户：客户消费统计

**统计指标**:
- 销售总额
- 回款总额
- 提成总额
- 销售数量
- 客户数量
- 平均客单价

**备份功能**:
- 自动备份
- 手动备份
- 备份文件管理
- 数据恢复

**备份策略**:
- 每日自动备份
- 保留最近30天备份
- 备份文件压缩存储
- 备份完整性验证
