## Product Backlog (Initial)

### Epics
- Authentication & Authorization
- Client Management
- Client Questionnaire
- Sales & Operations
- Reporting & Analytics
- Admin & Settings

### Top Stories
1. As an admin, I can sign in/out to a secure session.
2. As a user, I can view a dashboard with key metrics.
3. As staff, I can CRUD clients (name, contact, notes).
4. As staff, I can capture client questionnaire responses.
5. As staff, I can search and filter clients by fields.
6. As manager, I can view sales performance by shop and time.
7. As admin, I can manage employees and roles.
8. As devops, I can see app health and logs.

### Acceptance Criteria Example (CRUD clients)
- List clients with pagination and search
- Create/edit/delete with validation
- API responds with standard error format
- Success and error toasts on the frontend
- E2E test covers add/edit/delete flow
