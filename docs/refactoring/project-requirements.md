# YueHeApp 项目需求和约束

## 1. 项目背景

**项目名称**: 悦和国际美容院管理系统 (YueHeApp)  
**项目类型**: 企业级美容院运营管理平台  
**目标用户**: 美容院管理人员、员工、客户  
**业务领域**: 美容院运营管理、客户关系管理、销售管理  

## 2. 核心需求

### 2.1 功能需求

#### 2.1.1 用户管理
- **用户认证**: 用户名密码登录，支持角色权限
- **角色管理**: 专家、操作人、管理员等不同角色
- **权限控制**: 基于角色的功能访问控制
- **会话管理**: 安全的用户会话管理

#### 2.1.2 客户管理
- **客户注册**: 新增客户基本信息
- **客户查询**: 支持多条件查询和筛选
- **客户编辑**: 修改客户信息
- **客户删除**: 删除客户记录（需检查关联数据）
- **客户问卷**: 客户需求调研管理
- **客户档案**: 客户服务历史档案

#### 2.1.3 美容院管理
- **美容院注册**: 新增美容院信息
- **美容院查询**: 支持多条件查询
- **美容院编辑**: 修改美容院信息
- **折扣管理**: 设置美容院专属折扣
- **提成规则**: 配置店铺提成规则
- **客户统计**: 各美容院客户数量统计

#### 2.1.4 销售管理
- **销售记录**: 创建新的销售记录
- **销售查询**: 支持多维度查询和筛选
- **销售编辑**: 修改销售信息
- **销售删除**: 删除销售记录
- **提成计算**: 自动计算员工和店铺提成
- **回款管理**: 跟踪实际回款和公司收入
- **销售统计**: 按时间、员工、美容院等维度统计

#### 2.1.5 操作管理
- **操作记录**: 记录具体的美容操作
- **操作查询**: 支持多条件查询
- **操作编辑**: 修改操作信息
- **操作删除**: 删除操作记录
- **工具使用**: 记录使用的美容仪器
- **操作统计**: 操作次数和效果统计

#### 2.1.6 员工管理
- **员工注册**: 新增员工信息
- **员工查询**: 支持多条件查询
- **员工编辑**: 修改员工信息
- **员工删除**: 删除员工记录
- **薪资管理**: 员工薪资信息管理
- **在职状态**: 员工离职状态管理
- **职责分配**: 员工角色和职责分配

#### 2.1.7 仪器管理
- **仪器注册**: 新增仪器信息
- **仪器查询**: 支持多条件查询
- **仪器编辑**: 修改仪器信息
- **仪器删除**: 删除仪器记录
- **采购管理**: 仪器采购信息管理
- **使用记录**: 仪器使用情况跟踪
- **维护管理**: 仪器维护和保养记录

#### 2.1.8 美容项目管理
- **项目注册**: 新增美容项目
- **项目查询**: 支持多条件查询
- **项目编辑**: 修改项目信息
- **项目删除**: 删除项目记录
- **价格管理**: 项目价格设置和调整
- **项目统计**: 项目销售情况统计

#### 2.1.9 报表管理
- **销售报表**: 销售业绩统计报表
- **客户报表**: 客户信息统计报表
- **员工报表**: 员工业绩统计报表
- **财务报表**: 收入、提成、成本统计
- **导出功能**: 支持CSV、Excel、PDF格式导出
- **日期筛选**: 支持按日期范围筛选数据

#### 2.1.10 系统管理
- **用户管理**: 系统用户账户管理
- **角色管理**: 系统角色定义和管理
- **权限管理**: 功能权限分配
- **系统配置**: 系统参数配置
- **数据备份**: 数据备份和恢复
- **日志管理**: 系统操作日志记录

### 2.2 非功能性需求

#### 2.2.1 性能需求
- **响应时间**: 页面加载时间不超过3秒
- **并发用户**: 支持100个并发用户同时使用
- **数据处理**: 支持10万条以上数据记录
- **查询性能**: 复杂查询响应时间不超过5秒
- **吞吐量**: 支持每秒1000次请求

#### 2.2.2 可用性需求
- **系统可用性**: 99.5%以上的系统可用性
- **故障恢复**: 系统故障后30分钟内恢复
- **数据备份**: 每日自动数据备份
- **容错处理**: 优雅的错误处理和用户提示
- **维护窗口**: 支持在线维护和更新

#### 2.2.3 安全性需求
- **身份认证**: 强密码策略和登录验证
- **权限控制**: 基于角色的细粒度权限控制
- **数据安全**: 敏感数据加密存储
- **操作审计**: 完整的操作日志记录
- **网络安全**: 防止SQL注入、XSS攻击等

#### 2.2.4 可维护性需求
- **代码质量**: 遵循Java编码规范和Spring Boot最佳实践
- **模块化设计**: 清晰的模块划分和依赖关系
- **文档完整**: 完整的代码注释和API文档
- **测试覆盖**: 单元测试和集成测试覆盖
- **版本控制**: 完善的版本管理和发布流程

#### 2.2.5 可扩展性需求
- **水平扩展**: 支持多实例部署
- **数据库扩展**: 支持数据库读写分离
- **功能扩展**: 支持新功能模块的快速集成
- **接口扩展**: 支持RESTful API接口扩展
- **微服务**: 支持微服务架构改造

## 3. 技术约束

### 3.1 技术选型约束
- **前端技术**: 必须使用现代前端框架（React/Vue/Angular）
- **后端技术**: 必须使用Java技术栈（Spring Boot）
- **数据库**: 必须使用关系型数据库（MySQL/PostgreSQL）
- **部署方式**: 必须支持容器化部署（Docker）

### 3.2 性能约束
- **内存使用**: 单实例内存使用不超过2GB
- **CPU使用**: 单实例CPU使用不超过50%
- **存储空间**: 数据库存储空间不超过100GB
- **网络带宽**: 单用户网络带宽不超过1Mbps

### 3.3 兼容性约束
- **浏览器兼容**: 支持Chrome、Firefox、Safari、Edge最新版本
- **移动端兼容**: 支持iOS 12+、Android 8+
- **数据库兼容**: 支持MySQL 8.0+、PostgreSQL 12+
- **Java版本**: 支持Java 11+、Java 17+

## 4. 业务约束

### 4.1 数据约束
- **数据完整性**: 必须保证数据的完整性和一致性
- **数据安全**: 敏感数据必须加密存储
- **数据备份**: 必须支持数据备份和恢复
- **数据迁移**: 必须支持数据迁移和升级

### 4.2 业务规则约束
- **提成计算**: 必须按照业务规则自动计算提成
- **权限控制**: 必须严格按照角色权限控制功能访问
- **数据验证**: 必须对用户输入进行严格验证
- **业务流程**: 必须遵循既定的业务流程

### 4.3 合规性约束
- **数据保护**: 必须符合数据保护法规
- **隐私保护**: 必须保护用户隐私信息
- **审计要求**: 必须支持审计和合规检查
- **安全标准**: 必须符合安全标准和规范

## 5. 用户体验需求

### 5.1 界面设计
- **外观简洁**: 界面设计简洁大方，符合现代审美
- **操作便捷**: 操作流程简单直观，减少用户学习成本

### 5.2 交互体验
- **响应速度**: 操作响应迅速，无卡顿现象
- **错误提示**: 友好的错误提示和帮助信息

- **快捷键**: 支持常用操作的快捷键

### 5.3 可访问性
- **无障碍访问**: 支持屏幕阅读器等辅助技术
- **多语言支持**: 支持中英文界面切换
- **字体大小**: 支持字体大小调整
- **色彩对比**: 确保足够的色彩对比度
