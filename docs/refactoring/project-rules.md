# YueHeApp 项目规则和约束

## 项目规则

### 1. 技术选型规则
- **前端必须使用**: Next.js + React + TypeScript
- **后端必须使用**: Spring Boot 3.2+ + Java 17+
- **数据库必须使用**: MySQL 8.0+ + Redis
- **部署必须支持**: Docker + Kubernetes
- **UI组件库**: Ant Design (企业级UI组件)

### 2. 性能规则
- **页面加载时间**: 必须 < 3秒
- **接口响应时间**: 必须 < 500ms
- **并发用户数**: 必须支持100个并发用户
- **数据记录数**: 必须支持10万条以上数据
- **系统可用性**: 必须 > 99.5%

### 3. 代码质量规则
- **TypeScript**: 前端必须使用TypeScript，禁止使用JavaScript
- **代码规范**: 必须遵循ESLint + Prettier规范
- **测试覆盖**: 单元测试覆盖率必须 > 80%
- **代码审查**: 所有代码必须经过代码审查
- **文档完整**: 所有API必须有完整的文档

### 4. 架构规则
- **前后端分离**: 必须采用前后端分离架构
- **RESTful API**: 必须使用RESTful API设计
- **模块化设计**: 必须采用模块化设计
- **微服务就绪**: 架构必须支持微服务改造
- **容器化**: 必须支持Docker容器化部署

### 5. 安全规则
- **身份认证**: 必须使用JWT或OAuth2认证
- **权限控制**: 必须使用基于角色的权限控制(RBAC)
- **数据加密**: 敏感数据必须加密存储
- **HTTPS**: 生产环境必须使用HTTPS
- **输入验证**: 所有用户输入必须验证

### 6. 用户体验规则
- **响应式设计**: 必须支持移动端和桌面端
- **界面简洁**: 界面必须简洁大方，符合现代审美
- **操作便捷**: 操作流程必须简单直观
- **错误提示**: 必须提供友好的错误提示
- **加载状态**: 必须显示加载状态和进度

## 项目约束

### 1. 时间约束
- **总开发周期**: 不超过6个月
- **迭代周期**: 2周一个迭代
- **里程碑**: 必须设置明确的里程碑
- **上线时间**: 必须在规定时间内上线

### 2. 资源约束
- **开发团队**: 团队规模有限，需要合理分配任务
- **技术能力**: 团队需要学习新技术栈
- **预算限制**: 项目预算有限，需要控制成本
- **外部依赖**: 尽量减少外部依赖

### 3. 技术约束
- **兼容性**: 必须保持与现有系统的兼容性
- **数据迁移**: 必须保证数据迁移的完整性
- **渐进式**: 采用渐进式重构，避免大爆炸式改造
- **向后兼容**: 新版本必须向后兼容

### 4. 业务约束
- **数据完整性**: 必须保证数据的完整性和一致性
- **业务规则**: 必须遵循既定的业务规则
- **权限控制**: 必须严格按照角色权限控制
- **审计要求**: 必须支持审计和合规检查

## 开发规范

### 1. 命名规范
- **文件命名**: 使用kebab-case (如: user-service.ts)
- **类命名**: 使用PascalCase (如: UserService)
- **方法命名**: 使用camelCase (如: getUserById)
- **常量命名**: 使用UPPER_SNAKE_CASE (如: MAX_RETRY_COUNT)

### 2. 代码结构
- **目录结构**: 按功能模块组织代码
- **文件组织**: 一个文件一个类/组件
- **导入顺序**: 第三方库 -> 内部模块 -> 相对路径
- **注释规范**: 必须为所有公共方法添加注释

### 3. Git规范
- **分支策略**: 使用Git Flow分支策略
- **提交信息**: 使用约定式提交规范
- **代码审查**: 所有代码必须经过审查才能合并
- **版本标签**: 使用语义化版本号

### 4. 测试规范
- **单元测试**: 每个服务类必须有单元测试
- **集成测试**: 主要业务流程必须有集成测试
- **端到端测试**: 关键用户路径必须有E2E测试
- **测试数据**: 使用测试数据工厂模式

## 部署规范

### 1. 环境规范
- **开发环境**: 本地开发环境
- **测试环境**: 集成测试环境
- **预生产环境**: 生产前验证环境
- **生产环境**: 正式运行环境

### 2. 配置规范
- **配置管理**: 使用环境变量和配置文件
- **密钥管理**: 敏感信息必须加密存储
- **配置验证**: 启动时必须验证配置
- **配置文档**: 所有配置必须有文档说明

### 3. 监控规范
- **日志规范**: 使用结构化日志格式
- **指标监控**: 必须监控关键业务指标
- **告警机制**: 异常情况必须及时告警
- **性能监控**: 必须监控系统性能指标
